# Security policy

Please do not disclose security vulnerabilities in a public issue. Use a
private GitHub security advisory for this repository and include a concise
description, affected release or commit, reproduction steps that use only
synthetic data, and the likely impact.

Marketplace is designed to fail closed at service, operator-session, Portal,
Rules, tenant, and provider boundaries. A successful build, health response,
or local fixture is not proof that a deployment is authorized or safe for
production data.
